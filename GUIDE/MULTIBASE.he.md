# מכ״ם 3.1.0 — ניהול כמה בסיסים

זו המהדורה המקומית האחרונה עם תמונת מצב פיקודית. התקנה ושדרוג מחייבים: INSTALLATION.he.md. FRONT עולה לספריית SharePoint, SERVER ליישום IISNode ו־GUIDE נשאר מחוץ לשורש האתר. SERVER כולל תלויות production; אינו כולל Node או Mongo ואינו דורש התקנתם מחדש אם התשתית המאושרת קיימת.

אותו API ואותו מסד ארגוני משרתים כמה בסיסים. בורר מופיע רק למשתמש שיש לו לפחות שני בסיסים פעילים מורשים. המרחבים, החיפוש, התצ״א, הבדיקות, הפערים, התיעוד והייצוא שייכים לבסיס הנבחר. שינוי בסיס מאתחל את מסכי העריכה.

## 2. הרשאות

| תפקיד | בסיסים ומרחבים | סמכויות ניהול |
| --- | --- | --- |
| בעלים | כל הבסיסים, כולל בסיסים עתידיים | שליטה מלאה והתאמה אישית; היחיד שרשאי למנות, לשנות או להסיר מנהלים פיקודיים |
| מנהל מערכת פיקודי | כל הבסיסים, כולל בסיסים עתידיים | ניהול תפעולי מלא, יצירה/מחיקה/שחזור של בסיסים, מינוי ושינוי מנהלי בסיסים וניהול משתמשים. אינו ממנה מנהלים פיקודיים ואינו מקבל את אפשרויות הבעלים הבלעדיות |
| מנהל מערכת | בסיס אחד או כמה בסיסים שהוקצו ידנית | ניהול תפעולי מלא בהם. רואה ומנהל רק הרשאות בבסיס הנבחר, בלי מידע על שיוכים אחרים. אינו יוצר/מוחק בסיסים ואינו ממנה מנהלים |
| טכנאי | בסיסים ומרחבים שנבחרו ידנית | בדיקות, פערים ועריכת אמצעים בהתאם להרשאתו |
| מפקד מרחב | בסיסים ומרחבים שנבחרו ידנית | צפייה מורחבת ובקשות בדיקה |
| נציג מרחב | בסיסים ומרחבים שנבחרו ידנית | צפייה במרחבים ובאמצעים שלו |

לכל חשבון יכולות להיות הרשאות שונות בכל בסיס. בעלים ומנהל פיקודי הם תפקידים כלל־מערכתיים; יתר התפקידים נקבעים לכל בסיס בנפרד. אין הקצאת הרשאות אוטומטית מקבוצת AD. ״כל המרחבים״ כולל מרחבים עתידיים **רק בבסיסים שנבחרו**, ולא בסיסים חדשים. גישה לבסיסים חדשים ניתנת אוטומטית רק לבעלים ולמנהל הפיקודי.

מנהל בסיס מוסיף משתמש לפי sAMAccountName כרגיל, גם אם החשבון כבר קיים בבסיס אחר. המערכת מוסיפה רק הרשאה מקומית, ללא שכפול זהות וללא מסירת מידע על קיום החשבון בבסיסים אחרים. עריכה או הסרת הרשאה מקומית אינן משנות שם, דוא״ל, תפקיד או גישה בבסיס אחר. השם וכתובת הדוא״ל שמנהל בסיס מזין הם פרטים מקומיים לבסיס. רשימת המשתמשים שלו מציגה רק את הבסיס הנבחר, גם אם הוא מנהל כמה בסיסים.

בעלים ומנהל פיקודי רואים את השיוכים המלאים ועורכים לכל בסיס תפקיד, מרחבים ומצב הרשאה. הם יכולים גם להשבית חשבון בכל המערכת. השבתה כלל־מערכתית גוברת על הרשאה מקומית פעילה; מנהל בסיס אינו רשאי לבטל השבתה מרכזית. מינוי מנהל בסיס מותר לשניהם; מינוי מנהל פיקודי נשאר בידי הבעלים בלבד.

חשבון הבעלים מוגן מפני הסרה, השבתה, שינוי שם התחברות והורדת תפקיד. ההרשאות נבדקות מחדש בכל בקשה. ביטול שיוך לבסיס נכנס לתוקף בבקשה הבאה. שינוי תפקיד מקומי חל בבקשה הבאה בלי להשפיע על החיבור לבסיס אחר. שינוי תפקיד כללי, שם התחברות או השבתת חשבון מרכזית מבטלים גם חיבורים קיימים. עריכת הרשאות כוללת בדיקת גרסה למניעת דריסה של עדכון מקביל.


## ניהול בסיסים

בעלים ומנהל פיקודי יוצרים בסיס לפי שם, ומקצים מנהלים ומשתמשים. בסיס חדש מתחיל ללא מרחבים, ללא תצ״א וללא רשימת תפוצה; יש להגדיר מדיניות בדיקות, רשתות, SLA ותזכורות בהתאם לצורך. לכל בסיס תצ״א נפרדת עם סימונים ממודרים. מחיקה היא לוגית ושומרת תיעוד; משוחזר רק בידי בעלי הגישה המרכזית. בסיס מחוק אינו מופיע בסיכומים, אינו נגיש ואינו מקבל שליחת דואר.

לנציג ולמפקד ניתן לבחור כמה מרחבים וכמה בסיסים. אפשר לתת תפקיד שונה בכל בסיס. בחירה בכל המרחבים כוללת גם מרחבים עתידיים באותם בסיסים. העשרת AD אינה יוצרת הרשאה. אין להזין דומיין או סיסמה בפתיחת הרשאה, רק sAMAccountName.

## שדרוג והגנת נתונים

עדכנו FRONT ו־SERVER מאותה חבילה. בצעו downtime וגיבוי מסד מלא, preflight ואחריו apply/verify. המיגרציה קוראת את קטלוג bases וקידומות האוספים הקיימים; היא אינה מאחדת בסיסים, מחליפה מזהים או מוחקת grants. היסטוריה, תמונות ותור דואר נשמרים. אין מיגרציה אוטומטית בעת start או recycle. הוראות resume/restore וההשפעה של rollback מפורטות במדריך ההתקנה.

## בדיקות מקומיות וקבלה

בתחנת הפיתוח בלבד, START-LOCAL.ps1 מפעיל תצוגת בדיקה על 127.0.0.1:4322 עם מסד readiness_test_multibase_preview בשירות Mongo המקומי על 27029. יש החלפת משתמשים; דואר ו־LDAP כבויים. הקיצור וה־fixtures אינם בחבילת SERVER הארגונית. נתוני הגרסה המקומית הקודמת אינם משתנים.

בשרת הארגון לא מפעילים npm או START-LOCAL: IISNode מפעיל את src/server.js בעצמו. הזיהוי דרך Windows Authentication וקידום native ב־IIS, ו־SharePoint מארח את FRONT. TRUSTED_IDENTITY_VERIFIED נשאר false בייצור עד דוח קבלת DevOps. בדיקות חווה ושרת ארגוניים: NOT RUN.
